Webサイトの作り方

HTMLとCSSを使ってWebサイトを作る方法

ホーム HTML CSS タグ一覧 作り方 お問い合わせ

1. HTMLを作る

HTMLを使って、Webページの文章や見出し、画像などの 構造を作ります。

2. CSSでデザインする

CSSを使って、文字の色や大きさ、背景、レイアウトなどを デザインします。

3. ブラウザで確認する

作ったHTMLファイルをブラウザで開いて、 Webサイトが正しく表示されるか確認します。

4. 少しずつ改良する

色やレイアウトを変更したり、新しいページを追加したりして、 自分だけのWebサイトにしていきます。
